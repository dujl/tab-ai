# 首次接入机器人

尚未安装时先阅读 [安装指南](installation.md)。下文使用源码仓库中的 npm 命令；安装包用户将 `npm start --` 换成 `tab-ai` 即可，例如 `tab-ai setup`。已安装包无需在安装目录执行 npm ci/build，首次运行直接使用 `tab-ai init`，已有配置添加 Bot 使用 `tab-ai setup`。

## 终端向导

```bash
npm ci
npm run build
npm start -- init
```

选择接入平台，按提示完成操作。已有配置时不会覆盖，之后添加机器人使用 `npm start -- setup`。SSH 交互终端也可以使用，无需桌面或显示器。

飞书默认流程：**选择飞书 → 扫码创建与授权 → 给机器人私聊发送配对命令 → 回到向导确认用户身份 → 完成**。程序自动取得应用凭证、机器人 ID 和用户 ID，保存配置，不需要手填白名单。二维码由本机根据官方授权链接生成，也可在自己的设备打开授权链接。

扫码创建的默认名称为 `tab-ai-bot1`、`tab-ai-bot2`，编号按本实例已接入机器人、未完成配置及历史预留编号递增。已知名称中更大的编号也会被保留；授权页手动修改名称后，以平台返回的实际名称保存。编号在请求平台前持久化，取消、失败或删除机器人后不复用，因此可能跳号。恢复未完成配置不分配新编号。此编号范围是当前数据目录，不会枚举整个飞书租户或其他机器上的机器人；接入已有应用不会修改其平台名称。

飞书使用[官方 Node SDK 的应用注册能力](https://github.com/larksuite/node-sdk)，实际开放范围、审批要求及权限预填由平台/租户决定。若扫码创建不可用，可选择已有应用凭证接入；若无法配对，检查机器人能力、长连接事件订阅、消息权限、发布状态和可用范围。点击审批/选择卡片还需在回调配置中启用长连接 card.action.trigger。向导只有收到私聊并成功发送回执后才允许确认，不将拿到凭证当成接入成功。

企业微信默认流程：**选择企业微信 → 扫码创建 / 授权 → 私聊发送“你好” → 核对账号并确认启用**，无需 `/tab pair`。Bot ID 和 Secret 自动获取，无需手工复制；手机确认与租户审批仍需本人完成。已有机器人可选凭证接入。企业微信指 API 长连接智能机器人，不是个人微信或传统群 Webhook；详见 [企业微信接入](wechat-wecom.md)。

钉钉默认流程：**选择钉钉 → 扫码创建 / 绑定 → 在手机上确认 → 私聊机器人发送“你好” → 回到向导核对账号并确认启用**。Client ID 和 Client Secret 自动保存，无需手工复制凭证或配对码。向导生成 `tab-ai-botN` 作为本地显示名和建议名称；钉钉客户端名称需在官方页面设置，当前扫码协议不自动预填。已有应用可选择手动凭证接入。完整步骤、长任务回复权限和排障见 [钉钉接入](dingtalk.md)。卡片可留空，默认使用文字交互；自定义卡片需另配本租户模板，参见 [聊天交互指南](chat-interactions.md)。

未启动后台时，完成后执行：

```bash
npm start -- serve
```

后台已运行时，`setup` 自动使用同一个服务，并在确认后立即启用连接。

## 网页向导

不使用终端交互时，先启动服务：

```bash
npm start -- init --local
npm start -- serve
```

在另一个终端输出接入地址：

```bash
npm start -- dashboard --setup
```

打开输出链接，按页面完成授权、配对和确认。尚无机器人时，普通 `dashboard` 也会进入向导。已有工作台的侧栏提供“接入机器人”。链接包含本地管理令牌，不要转发给其他人。

## 无显示器服务器

服务继续运行在服务器。使用自己的电脑建立 SSH 转发，然后在自己电脑的浏览器打开服务器输出的 `http://127.0.0.1:4317/setup#token=...` 链接：

```bash
ssh -N -L 4317:127.0.0.1:4317 user@server
```

服务器不需要图形界面或浏览器，也不需要公网回调地址；二维码在自己的电脑上显示，用手机扫码。CLI 向导则可直接通过 SSH 终端显示二维码。平台授权步骤仍由用户在自己的设备完成。

## 取消、重启和凭证

- 配对码有效期 5 分钟，只接受私聊。手动凭证接入以持有码并最终获本地确认的用户为准；不要转发配对码。
- 回到向导确认后，该用户才加入机器人白名单。初始化不会执行 Codex / Claude 任务，不向 agent 注入设置指令。
- 取得的凭证存入 `~/.tab-ai/data/setup-drafts/`，重新打开向导可以继续。尚未取得凭证的扫码授权需重试；如果平台已经创建了应用但响应丢失，请先检查平台后台，再选择已有应用接入。
- 取消或配对失败不删除平台应用，不启用机器人；重启继续时使用新的配对码。
- 成功后凭证存 `~/.tab-ai/data/credentials.json`，权限 0600；配置保存凭证引用与允许的用户 ID。文件没有额外加密，应像本机 agent 登录凭证一样保护，不要提交到 Git。
- 保留高级手动配置与环境变量覆盖；向导不修改 agent 的原生登录、提示词或工作区配置。

机器人接入完成不代表模型账号已登录。Codex / Claude Code 仍需按原生方式在服务器上完成登录。

## 个人微信

向导选择“微信（个人微信）”，扫码并完成手机确认；若要求验证码，在向导输入。随后用扫码账号私聊机器人发送任意文字，收到回执后确认启用。无需手工复制 Bot Token 或用户 ID。具体主子会话、引用回复和当前能力范围见 [微信与企业微信](wechat-wecom.md)。
