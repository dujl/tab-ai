# 同一任务的网页与 IM 双入口

双入口适用于同一运行实例、同一任务及 Session 的网页与当前 IM 协作；不包含跨通信平台迁移、自动故障切换或跨原生 Agent 无损迁移。

## 任务与会话

Tasks、Agents、Bots 分别表示工作、执行者与聊天入口。Task 管目标、父子关系、队列、依赖、进度及验收；Session 管原生上下文、模型、目录、审批和执行状态。网页与 IM 操作同一 sessionId；同一节点最多一个原生执行轮。不同节点可以选择 Codex、Claude Code 或 OpenCode，完整对话不自动复制到其他节点。

统一任务目录投影 Session 与 TaskRecord。使用任务工具或新增编排子任务时，框架按当前绑定和授权范围登记任务能力，保留原生上下文与导航标识；查看目录本身不会启动工作。登记和报告映射规则见 [数据模型](database.md#任务记录登记)。

任务工具注册在会话专属 loopback MCP 上，只有原 Session 的当前有效、未停止执行轮能调用；接口无全局管理令牌，不能操作无关任务。会话内地址稳定以兼容原生连接复用，服务关闭后失效。Codex 创建线程时注册动态工具；恢复未注册动态工具的线程时，通过 `thread/resume.config` 的独立 `mcp_servers.tab_ai_tasks` 配置接入，不修改共享配置文件。协议参考：[官方 App Server](https://learn.chatgpt.com/docs/app-server)。

## 两个入口的共同操作

网页对话按 sessionId 继续原 nativeId；IM 按已绑定聊天定位同一 Session。模型、审批、停止、开关、压缩、目录和重置均落到同一后台对象。调度任务的补充进入持久 TaskJob 队列，交互节点忙时明确拒绝；不会同时启动两个执行轮。IM 权限、Manager BOT 单聊的全局管理限制及网页 bearer 认证分别校验。

任务工作轮附带当前分支的只读目标、状态、版本和成果摘要，主节点能感知全部下级；下级不获得兄弟或其他任务的控制权。完整报告送直接父任务验收，不越级代验。task_progress 仅保存进度，不结项或唤醒父任务；用户明确使用 `/tab topic-report <摘要>` 时可汇报阶段进展。整体完成用 task_report，父节点使用 task_review 接受或返工；有未完成子任务、待处理输入或待用户回答时不能提交最终结果。空闲、一轮结束和关闭都不代表目标完成。

网页和 IM 的审批共用一个请求，首个有效决定生效，重复决定拒绝；即使前置 IM 文字投递阻塞，网页也立即可见待处理请求，IM 卡片仍保持消息顺序。普通 IM 文字等待有界且不自动重发，投递超时不把已完成的原生工作误判为模型超时。飞书更新原卡片终态，不支持原地更新的平台使用其实际可用提示。旧原生请求重启后不能恢复为有效授权。

新子任务默认继承直接父任务目录。可在原生适配器支持时明确修改本节点目录，保留上下文、模型和其他节点目录；已有历史的 Claude 不支持该迁移时明确拒绝。有本节点排队输入、下载、原生终端占用或执行中时拒绝切换，避免已排队简报使用错误目录。共享目录没有自动文件隔离或 worktree。

重置需要明确确认及 revision 校验。交互节点：创建新上下文，旧会话关闭保留。任务节点重置只清空本节点的原生上下文标识，保留 taskId、sessionId、父子关系、设置及框架历史；旧 nativeId 写入 context_reset 记录。不会清除任务成果或重跑工作；有待执行输入、运行或已取消状态时拒绝。压缩继续使用同一 nativeId，与重置不同。

## 通信故障与任务入口

各 IM 独立初始化和启动。一个通道缺少凭据、启动失败或超时，不关闭 Dashboard、任务服务及其他通道；Dashboard Bots 展示启动状态。ready 表示连接启动完成，不代表持续网络健康检测。没有自动切换通道。

新建任务时明确选择“仅网页”或已有 IM 来源，选择来源时目录同步为该来源目录。仅网页任务不隐式绑定 IM。沿用 IM 来源的子任务即使创建飞书话题失败，仍在原 Session/Task 树建立，可通过网页继续；imEntry 标记 pending（未尝试）或 unknown（结果不确定），回复和记录保存在网页，不因此重跑 Agent。

恢复后可在该任务网页补建**原 BOT、原聊天、原用户**的飞书话题。unknown 必须先核对原群并明确确认，不能自动重试不确定投递。补建过程锁住本节点新执行，原子更新路由与 TaskRecord，保留 Session、nativeId 和父子关系，旧虚拟绑定删除；重复成功请求不再次创建。补建仅恢复同一 IM 的任务入口，不允许改成其他 BOT、群或平台。平台收发仍依赖该 BOT 自身有效的连接和权限。

## 验证

自动测试覆盖双入口输入、混合 Agent 嵌套任务、审批去重、阶段进度、逐级验收、上下文保留、任务登记、目录、重置及连接初始化失败时的网页可用性。浏览器验收使用隔离数据、Fake Agent 和 Fake Channel，分别检查局域网 HTTP 与手机布局。

可重复验收方法见 [验收](acceptance.md)。

## 交付接续

关闭会话、提交成果会创建持久化版本报告；父任务和已声明依赖的下游读取交付规格、验证、遗留事项和有依据的经验。下游调度固定报告版本，不因空闲或关闭就视为完成。详见 [交付报告与可复用经验](session-reports.md)。
