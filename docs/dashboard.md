# Dashboard 操作指南

## 打开与认证

运行 `tab-ai dashboard` 获取带访问令牌的地址；访问普通地址时也可输入原有本机 token。令牌从 URL fragment 读取后立即从地址栏清除，保存在当前标签页 sessionStorage 中。

默认只监听本机。需要同局域网访问时，配置 `dashboardLanHost` 为本机私有 IPv4 地址，例如 `192.168.1.10`，使用 `http://192.168.1.10:4317/`。仍须原有 bearer 认证，服务只接受本机及显式配置的局域网 Host / Origin。`tab-ai dashboard` 在此配置下显示对应局域网登录链接。

这是实例管理入口，允许查看全实例任务、原生对话与机器人配置；不等同于群聊用户的权限视图。聊天中的身份、BOT 角色与群模式仍独立校验。

## Tasks · 任务

所有工作统一进入“任务”，不再按“普通 / 任务”分类。有无子任务只是是否已经拆分，不改变产品对象。旧聊天及 TaskRecord 由统一任务目录投影，保留原生 ID、目录、设置、历史及父子关系，不自动重建、唤醒或将阶段报告改成最终完成。目标缺失明确显示“待明确目标”。

左侧显示顶层任务与最近使用。名称、目标、ID、BOT、目标状态和执行状态可筛选；搜索下级能找到该节点，并在主区保留完整祖先路径。左侧不无限缩进展开深树。

右侧按能力提供以下页签：

- **任务结构**：分层导航与可折叠大纲共享同一棵树。分层导航最多展示相邻三列，选中路径加深时移动窗口，保持文字宽度。大纲查看分工与状态；搜索时保留匹配节点的祖先。
- **对话**：进入选中任务的独立原生上下文，查看消息、工具记录、问题、审批与执行设置。输入不会广播给下级。
- **审批与执行**：按审批 ID、轮次 ID、工具 ID 或关键词查看历史，展开请求/输入/输出/退出码并加载更早记录；页首保留待审批操作。已允许与执行成功分开标记。详见 [记录存储与查询](execution-records.md)。
- **Agent 待办**：按实际 Agent 能力显示原生执行计划与轮次历史。
- **交付与经验**：查看目标、验收条件、版本化报告、接续规格、验证、产物、遗留与经验来源；有调度能力的任务保留暂停、继续、取消子树和原生验收流程。

“聚焦此任务”只改变主区浏览范围；“返回上级”“查看整棵树”及面包屑可返回祖先。选中节点、分支、页签与展示模式写入 URL，刷新和前进/后退恢复定位；轮询不改变选择与折叠。各任务草稿独立保存在当前页面内存中。

目标状态与执行状态分别显示：执行空闲、对话关闭和一轮结束都不表示目标完成。历史无类型报告标为未确认整体完成，不把“准备工作完成”包装成整个任务完成。

## 新建与拆分

“新建任务”是唯一入口。填写名称，可补充目标、验收条件、Agent、工作目录和投递来源。无来源时直接创建本地任务，不需要先创建空白入口对话。新任务默认只建立并等待输入；勾选“创建后立即执行”时必须明确填写目标。

先建后执行的任务不创建初始执行队列，也不因为收到下级结果就提前唤醒。首次用户输入明确后进入原任务上下文；目标为空时以这次输入登记目标。创建按钮使用稳定 key，重试复用已创建记录；不重播已经开始的工具操作。容量不足而未开始的旧对话初始要求会保留，可重试或从原任务开始。

任一可用节点均可“新增子任务”，表单固定所选直接父级，不更换投递来源。旧对话保持自己的报告与生命周期，调度任务继续使用持久队列、依赖、父任务验收及新节点默认继承直接父级目录；统一目录不通过转换历史上下文伪造新能力。所有新增入口都称为任务，真实执行能力由后端决定。

任务支持根下最多 8 层子任务。调度树仍限制每树 32 个任务、每节点 12 个直接子任务；旧话题关联树仍保留每树 100 个后代的限制。达到限制时明确拒绝，不在原聊天默默创建替代任务。共享目录不自动提供文件冲突锁。

## Agents

独立展示 Codex、Claude Code、OpenCode、默认执行者、已有任务对话数及已接入的原生压缩、循环、保留上下文切目录等能力。“用此 Agent 新建任务”带入相应执行者。这里展示本机配置和适配器能力，不将其当作实际网络健康探测。

任务“对话”页保留模型/思考设置、上下文压缩、原生终端交接、循环管理及工作目录切换。每项操作依照原生适配器及当前任务能力校验，不因菜单统一而绕过限制或工具审批。

## Bots

保留机器人接入、角色、授权人数、本机名称与默认目录管理。飞书 BOT 继续管理 mention/context/auto 群模式、权限申请链接及二维码；企微群补读说明保留。“查看任务”进入该 BOT 的任务筛选。

名称编辑只修改本机显示；默认目录只作用于以后新任务，不迁移已有工作。Manager 角色与群聊的全量消息权限是独立配置。机器人接入状态不代表实时连接健康。

## 总览与异常

总览统计统一任务、顶层任务、执行中与待确认，并保留原请求的审批入口。取消子树需要确认，保留历史；停止当前轮、关闭对话、暂停任务调度分别保持原有含义。

任务尚在创建、没有对话或关系异常时仍可查看，不按标题猜父级，不显示会误改其他节点的操作。手机通过“切换任务”展开入口列表，主区分层导航按列堆叠显示，不把深层文字缩到不可读。

### 待处理与最近使用

任务侧栏按「待你处理 → 待补充 / 初始化 → 最近使用 → 其他顶层任务」排列。实际未结束的工具审批、原生提问优先，按到期时间、发起时间排序；同一任务聚合显示审批和问题数量，点击进入该任务的「审批与执行」。异步提问可以在 Agent 仍运行时出现，不依赖会话的 waiting 状态。处理完成、过期或关闭会话后自动移出。

待补充只标记没有原生上下文且尚未填写目标的新建任务；旧会话缺少目标记录不代表需要用户干预。保存有 `pendingInitialTask` 的会话显示「待初始化」，对话页可展开原始任务并点击「确认并开始任务」，不会自动执行。

最近使用取最后一次用户消息、当前浏览器实际打开时间和创建时间的最大值，不使用工具输出或系统事件更新时间，避免后台执行刷屏影响导航。用户消息时间通过目录的 `lastUserAt` 返回，来自持久化 events；打开记录仅保存在本浏览器 localStorage（最多 100 个任务标识和时间）。最近项最多 6 个，已列在待处理区的任务不重复；搜索仍可找回全部历史。子任务附所属路径，列表排序不改变父子关系、执行状态或访问权限。所有区块遵守搜索、BOT 和状态筛选。

### 当前会话审批策略

「审批与执行」提供当前会话的审批策略及撤销授权入口。实际请求只展示 Agent 支持的选项；会话内允许不跨会话，关闭、重置、服务重启或原生状态回收后失效。缓存输入量仅在 Codex 实际上报后展示，缺失时标记尚未上报。参见 [会话审批策略与授权范围](session-approvals.md)。

### 展示范围

侧栏顶部「展示范围」提供「顶层任务」「全部任务」两个按钮，默认全部任务，选择保存在当前浏览器。全部任务时，最近使用之外的所有任务也可在其他任务区找到；顶层任务时，每个顶层任务只出现一次，下级的待审批、待回答和初始化提示汇总到顶层任务，提示将前往的具体任务，点击后进入对应处理页。搜索命中下级时仍展示所属顶层任务。模式只控制左侧列表，不改变右侧完整层级、当前选中任务或访问权限。数量分别显示顶层任务数及全部任务数。

### 局域网 HTTP 下的新建入口

浏览器在 `http://192.168.…` 等非安全上下文中可能不提供 `crypto.randomUUID()`。任务表单的幂等键使用该方法时必须检测能力，缺失时用 `crypto.getRandomValues()` 生成 UUID v4；不可直接调用导致整个表单打不开。编号生成失败会显示页面错误；创建请求失败则保留表单及同一个幂等键，供修正后重试。前端验收必须包含局域网 HTTP，不能仅以 localhost 成功代替。

## 网页与 IM 接力

网页对话继续原 Session，可与当前 IM 交替使用。新增子任务对历史父节点原地登记任务能力，保留原生上下文与稳定导航。根任务可选择“仅网页（不关联 IM）”或现有 IM 来源；来源目录会自动填入。子任务继承直接父任务目录，独立选择 Agent。

对话工具栏增加“重置上下文”：任务节点保留 Task/Session ID，普通兼容会话保留关闭的旧记录。切换工作目录可用于空闲且无排队输入的节点，适配器不支持时明确提示。Bots 页面展示连接启动失败，网页仍可使用。若飞书任务话题尚未建立，对话区说明具体状态，并提供补建原 BOT 话题入口；不确定投递必须先核对原群，明确确认后才补建，不更换通道。详见 [双入口任务](dual-entry-tasks.md)。

## Agent 待办

会话的「Agent 待办」页签展示原生执行步骤及已完成项目，支持状态筛选、各轮历史分页和实时刷新。入口按当前 Session 的实际能力展示；Claude 尚未确认或未开放任务工具时隐藏。框架父子任务继续使用「任务结构」。详见 [Agent 原生待办](agent-plans.md)。
