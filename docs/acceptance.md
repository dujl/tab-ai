# 验证与验收

本页定义可重复的验收流程和真实覆盖边界。测试日志、部署快照、备份及平台联调记录保存在运行实例的数据目录，不把特定机器、PID 或历史消息 ID 当作仓库要求。

可执行命令、分域回归、覆盖率及 CI 见 [测试指南](testing.md)。

## 基础检查

在隔离的开发数据上运行：

```sh
npm ci
npm run format:check
npm run docs:check
npm run check
npm test
npm run build
```

- 格式检查覆盖源码、测试、脚本、Markdown、静态页面和配置。
- 文档检查验证仓库内文件链接、引用锚点与示例引用的可用性。
- TypeScript 检查启用严格类型与未使用符号校验。
- 构建重新生成完整 `dist`，不打包已经从源码删除的旧模块。

## 需求覆盖矩阵

| 场景               | 自动验证                                                             |
| ------------------ | -------------------------------------------------------------------- |
| Task 与 Session 树 | 统一目录、父子关系、深度/规模、非法范围、归档、回填及重复迁移        |
| 双入口             | Web/IM 交替输入，同一 nativeId，每节点单轮，忙时队列，原聊天路由     |
| 多 Agent           | 启动/恢复参数、指令、模型、目录、工具事件、当前线程校验              |
| 任务接续           | 逐级验收、同级依赖、返工、祖先结论失效、报告版本与输入引用           |
| 交付与经验         | 关闭/取消/重开、活动轮收尾、总结恢复、事实降级、经验依据及范围       |
| 会话控制           | 目录继承、原地切换、重置、压缩、终端交接、原生循环能力               |
| 群模式与权限       | 私聊/群聊、@、消息权限入口、Manager 单聊边界、分支只读总览           |
| 审批与问题         | 原生实际选项、会话授权、重复/过期拒绝、超时通知、跨入口终态同步      |
| 附件               | 元数据登记、最近附件指代、候选选择、@寻址、下载/解密、身份及聊天范围 |
| Token 与压缩统计   | 当前/历史用量、原生 ID 校验、缓存/思考去重、压缩前后对比及失效采样   |
| 原生待办           | 事件范围、能力发现、计划状态、分页、模型/重置后失效                  |
| 安全与持久化       | Host/Origin/token、环境凭证过滤、原子写入、实例锁、备份快照与重启    |
| 聊天命令           | `/tab` 分发、普通原文保留、卡片权限、定向子任务与配对                |

测试代码以 `test/*.test.ts` 为准；新增行为应有可观察结果的回归，不用与实现逐行对应的断言替代行为验证。

## 浏览器验收

使用独立端口、临时数据库、Fake Agent 和 Fake Channel：

1. 验证 Tasks/Agents/Bots、节点选择、分层导航、大纲、搜索、分支聚焦及返回。
2. 新建根/子任务，核对父级、来源、默认目录、Agent、幂等重试和等待输入。
3. 核对对话草稿、审批/问题、原生待办、报告分页和生成状态。
4. 以至少 390px 手机宽度核对控件、长文本、可编辑目录与无横向溢出。
5. 使用局域网 HTTP 条件验证新建入口，不依赖 localhost 特有的 `crypto.randomUUID()`。
6. 收集页面异常；动态内容以纯文本显示，不因用户文本执行脚本。

正式实例可以只读核验目录和能力；不要为了界面测试向真实聊天发送任务或提交审批。

## 原生与平台联调

真实 Agent 使用新建隔离 Session 与合成输入，验证实际原生 ID、上下文、cwd、结构化输出和工具协议；需要有效登录与额度。模拟协议通过不代表所有 Provider、版本和登录方式均已验证。

真实 IM 分别检查：飞书消息与卡片回调订阅、群权限；企微 SDK 回调、Bot CLI 授权与附件；钉钉模板字段与权限；微信扫码后的收发和引用。平台配置存在或连接启动 ready，不代表真实客户端排版、点击及长期网络健康均已验收。

## 部署检查

- 等待运行、待审批、维护、终端接管、排队工作与向导流程结束，保护其他任务。
- 备份配置、SQLite 和必要的原生 Agent 数据；运行中备份使用 SQLite 机制。
- 检查源码对应的新构建，空闲重启同一数据目录。
- 核对会话/原生 ID、绑定、父子关系、历史、队列、报告和配置保持预期；不自动重放历史副作用。
- 检查已接入通道与网页可用，保存安全的部署结果，不写入密钥或原始回调。

当前实现及尚未覆盖的产品能力见 [实现评审](implementation-review.md)。
